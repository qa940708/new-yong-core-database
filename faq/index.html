常見問題 QUESTIONS & ANSWERS

01中文與亂碼 亂碼登入器打開後全是亂碼，如何解決？
  1. 開啟 Control Panel（控制台）。
  2. 點擊 Clock and Region（時間與地區）。
  3. 選擇 Administrative（系統管理）。
  4. 點擊 Change System Locale（變更系統地區設定）。
  5. 改成 中文（台灣）。
  6. 重新啟動電腦即可。
查看圖文教學↗
02啟動與安裝 ERROR CODE 5出現 ERROR CODE 5，無法打開登入器？

請先關閉防毒軟體，再重新安裝遊戲。
進入遊戲時也請保持防毒軟體關閉。

查看關閉防毒的操作步驟 →
03啟動與安裝 ERROR CODE 14001安裝後跳出 ERROR CODE 14001，怎麼辦？

不必理會，直接開啟遊戲資料夾，執行 LAUNCHER 即可遊玩。

04安全性與檔案 Windows 10 / 11如何關閉防毒？
  1. 開啟 Windows 安全性。
  2. 點擊 病毒與威脅防護。
  3. 在「病毒與威脅防護設定」中，點擊 管理設定。
  4. 關閉 即時保護。
查看圖片教學↗
05安全性與檔案 Windows 10 / 11檔案被防毒隔離、登入器顯示人數已滿，如何還原？
  1. 開啟 Windows 安全性。
  2. 點擊 病毒與威脅防護。
  3. 開啟 保護歷程記錄。
  4. 點選 已隔離威脅。
  5. 點擊 動作 → 還原。
查看圖片教學↗
06安全性與檔案 Windows 10 / 11如何把遊戲加入白名單，避免檔案被吃？
  1. 開啟 Windows 安全性。
  2. 點擊 病毒與威脅防護。
  3. 在「病毒與威脅防護設定」中，點擊 管理設定。
  4. 往下滑，找到 排除項目。
  5. 點擊 新增排除範圍。
  6. 選擇遊戲資料夾中的 Classic.exe 與 Game.exe。
查看圖片教學↗
07中文與亂碼 推薦拼音輸入法如何打中文？【搜狗拼音】
  1. 下載並安裝 搜狗拼音輸入法。
  2. 在搜狗拼音輸入法上按右鍵。
  3. 點擊 更多設定。
  4. 點擊 按鈕。
  5. 點擊 系統功能快捷鍵設定。
  6. 勾選 大五碼。
  7. 在遊戲內按下 Ctrl + Shift + W，即可輸入中文。

08中文與亂碼 BIG5 模式拼音輸入法如何打中文？【QQ 拼音】
  1. 下載並安裝 QQ 拼音輸入法。
  2. 開啟遊戲後，在 QQ 拼音輸入法上按右鍵。
  3. 選擇 切換輸入模式。
  4. 改為 BIG5 模式。

09啟動與安裝 VCREDISTSXSTRACE 問題如何解決？

  2. 雙擊並安裝裡面的 Vcredist_x86。

11連線問題 1.1.1.1 VPN無法連線，或遊玩一段時間後卡住、返回登入畫面？

如果已上線卻連不到遊戲，或進入遊戲後過一陣子卡住、回到登入畫面，請依照以下方式嘗試：

  1. 下載並安裝 1.1.1.1 VPN。
  2. 安裝完成後，開啟並連線。
  3. 再次嘗試登入遊戲。
  4. 如果可以正常遊玩，約 1 小時後可關閉 VPN 連線，再嘗試使用原本的 IP 遊玩。
