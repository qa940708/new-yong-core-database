# NEW YONG 怪物核心圖鑑

玩家公開查詢網站，資料來源為 NEW YONG 核心公開資料表。

## 玩家可查詢
- 怪物名稱與階級
- 核心名稱與五大核心類別
- 核心能力與實際數值
- 核心掉落率
- 區域與出沒地圖
- 收藏組

## 搜尋與篩選
支援怪物、核心、能力、地圖關鍵字搜尋，以及怪物階級、核心類別、能力、區域篩選。

> 核心顏色只代表分類，不代表強弱。官方提供資料，不限制玩家配裝方向。

## 維護
網站介面與資料分離。日後新增或修改核心時，更新 `cores/` 內的公開資料即可，玩家網址不需要更換。
