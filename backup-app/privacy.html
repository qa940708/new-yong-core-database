Privacy policy

Updated 22 October 2026

This notice describes the personal backup utility operated by qa940708. It covers the backup workflow and its Google Drive authorization.

Data accessed and its purpose

The utility reads the configured GitHub repository's committed files, history, references, release metadata, and release assets to create a backup archive.

Through the Google Drive API, the uploader accesses file and folder identifiers, names, metadata, and uploaded backup contents. It uses this data to locate the selected backup destination, create folders, upload archives, check uploaded bytes, and record successful verification. Setup also writes, checks, and deletes a temporary test file.

Google Drive permission

The utility requests https://www.googleapis.com/auth/drive to work with the owner's existing destination folder. This permission technically allows access to read, create, change, and delete Drive files. The uploader is configured to operate inside the selected backup folder; that configuration is a path restriction rather than a folder-specific Google authorization.

Credential storage

The OAuth client credentials and access and refresh tokens are stored locally in a directory restricted to the Windows user and system, and in an encrypted GitHub Actions repository secret. A workflow runner loads a temporary credential file to perform the upload and removes it when the backup process finishes. The uploader does not add its credential configuration to the backup archive.

Where data is processed and shared

GitHub Actions processes the repository data and temporary upload credentials while running the backup. Google Drive stores the resulting archives and processes the Drive API requests. Access also depends on the owner's repository permissions and Drive sharing settings.

The utility uses Google data only to carry out the requested backup and verification. It does not sell Google user data or use it for advertising or model training. This documentation site adds no analytics scripts or tracking cookies; its hosting provider may process ordinary web request logs.

Retention and deletion

Each successful run creates a separate backup. There is no automatic deletion policy. The owner controls how long archives remain and can delete them directly in Google Drive. Local setup credentials and the GitHub Actions secret remain until the owner removes or replaces them.

Stop access

The owner can disable the backup workflow in GitHub, remove its Actions secret, and revoke this app from Google Account connections. Revoking access stops future authorized API operations; existing archives remain until deleted by the owner.

Contact and changes

Use the support email displayed on the app's Google consent screen or contact qa940708 about this utility or its data handling. This page will be updated if the utility's data practices change.
