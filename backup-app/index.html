GitHub Drive Backup

A personal utility operated by qa940708 to save independent repository archives to the owner's selected Google Drive folder.

How it works

Once authorized and enabled, GitHub Actions creates an archive after supported repository push events or a manual run. Each archive includes committed files, Git history, branches, tags, referenced Git LFS objects, and downloadable release assets.

The uploader saves the archive to Google Drive, reads it back to verify its contents, and creates a SUCCESS.json receipt only when verification succeeds.

Google authorization

The owner signs in through Google and grants Drive access. The utility uses that access to locate the selected destination, create backup folders, upload archives, verify uploaded files, and remove its temporary setup test file. The requested permission and credential handling are explained in the privacy policy.

Storage and control

Backup copies remain in the owner's Google Drive until the owner deletes them. The utility has no automatic retention cleanup. The owner can disable the workflow and revoke its Google authorization at any time.

Documentation and support

Read the setup and restoration guide for backup coverage, limitations, and verification instructions.

For support, use the contact email shown on this app's Google consent screen or contact the repository owner. Keep credentials and private backup data out of public messages.
