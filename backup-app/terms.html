Personal use

This utility is operated by qa940708 for repositories and Google Drive storage controlled by that owner. Authorize only accounts and content you have permission to access and back up.

Backup coverage

The utility archives Git repository contents, history, references, referenced LFS objects, and release assets. Coverage depends on the configured workflows and the files available at the time of capture. Issues, pull request discussions, account settings, secrets, Actions artifacts, and uncommitted local files are outside its coverage.

Operating the backup

The owner manages authorization, available storage, workflow notifications, retention, and restoration. A backup is complete only when its folder contains the verification receipt SUCCESS.json. Check the archive checksum before restoring and periodically test restoration.

API availability, network failures, access changes, and storage limits can prevent a run from completing. The workflow reports those failures through GitHub Actions.

Data practices and support

The privacy policy describes data access, processing, storage, and revocation. Support is available through the email shown on the app's Google consent screen or the repository owner.
